# Contributing

You can't push to this repository. Contribute through a fork:

1. Fork this repository.
2. Clone **your fork**, and add this repository as a remote called `upstream`.
3. Branch from **`upstream/develop`**. `main` only changes at release time.
4. Copy `runbooks/TEMPLATE.md` (the one on `develop`) to `runbooks/<your-github-username>-<topic>.md`,
   all lower case. Fill in every section.
5. Push the branch to your fork and open a pull request into **`develop`**.

One runbook per pull request. If a check fails, fix it on the same branch: don't open a second pull request.
Pull requests are closed automatically after 14 days.
